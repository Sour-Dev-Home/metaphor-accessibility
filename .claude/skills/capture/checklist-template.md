# Checklist template

Post as one comment on the evening issue, starting with the `This was generated by AI.` line.

```markdown
## Session checklist (kit: `<branch>` at `<sha>`, every listener reviewed and stamped)

**Setup (Claude does this when asked):** run `scripts/dev/session.ps1 run -OptIn <names> -SaveLog <folder>` with the
opt-ins below and confirm `hooks <n>/<m>` with no `skipped: opt-in` and every listener installed. Quitting the game
saves `message-log.txt` and `transcript.txt` to the `-SaveLog` folder, outside the repo.

| Opt-in file | For |
|---|---|
| `opt-in-<name>.txt` | #<n> what it records |

Note any listener that floods the log or is risky to the game, and what to say if it misbehaves.

**Order of play** (OBS on, narrate what's on screen):

1. **<Area> (#<n>):** the actions, in order, one line.
2. ...
N. **If time allows:** #<n>, ...

#<n> needs no step: <why>. #<n> isn't in this kit: <why>.
```

Keep each step to one line. Tickets that read the player's own text (names) log lengths and matches only.
