# Player docs

For people installing and using the mods. The newest download is the pre-release `v0.0.1-unstable.3` on the
[releases page](https://github.com/Sour-Dev-Home/metaphor-accessibility/releases); there is no stable release yet, so
pages here are drafts for testers. Start with [Install the mod](how-to/install-the-mod.md).
[`../README.md`](../README.md) says which type of page goes in which folder.

- [Install the mod](how-to/install-the-mod.md) (draft): Reloaded-II, the game, the mod, a desktop shortcut and the keys.
- [Turn off the update check](how-to/turn-off-the-update-check.md) (draft): the one request the mod makes, and the
  setting that stops it.
- [Check a download](how-to/check-a-download.md) (draft): that a zip of the mod, a release or a dev build, is the
  one CI built.
- [Sound cues](reference/sound-cues.md) (draft): the short sounds the mod plays, what each means, and how to turn them
  off or change their volume.

Player pages must work with a screen reader: headings for structure, link text that makes sense on its own, and no
information given only by an image or a colour.
