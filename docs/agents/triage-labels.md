# Triage Labels

The skills speak in terms of five canonical triage roles. This file maps those roles to the label strings used in this
repo's issue tracker.

| Label in mattpocock/skills | Label in our tracker | Meaning                                  |
| -------------------------- | -------------------- | ---------------------------------------- |
| `needs-triage`             | `needs-triage`       | Maintainer needs to evaluate this issue  |
| `needs-info`               | `needs-info`         | Waiting on reporter for more information |
| `ready-for-agent`          | `ready-for-agent`    | Fully specified, ready for an AFK agent  |
| `ready-for-human`          | `ready-for-human`    | Requires human implementation            |
| `wontfix`                  | `wontfix`            | Will not be actioned                     |
| (none)                     | `needs-game`         | Needs your own copy of the game, or a play session, to do or check the work |
| (none)                     | `needs-game-session` | Only the maintainer can unblock this, in a game session |
| (none)                     | `good first issue`   | Small, with clear acceptance criteria, for a newcomer (no game needed) |
| (none)                     | `post-v0.1.0`        | Not needed for v0.1.0, chapter 1 playable blind |

When a skill mentions a role (e.g. "apply the AFK-ready triage label"), use the corresponding label string from this table.
