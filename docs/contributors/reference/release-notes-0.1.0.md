# Release notes: v0.1.0 (draft)

The text for the `v0.1.0` draft release on GitHub (#468). Paste the section below into the draft; the maintainer
edits it after the by-ear checks, and removes what they could not confirm. The mod is for the Steam version of
Metaphor: ReFantazio on PC, single-player only.

## Draft text

**Metaphor accessibility 0.1.0, early access**

This is the first release. It reads the game's dialogue and reply choices aloud through your screen reader, with a
spoken installer. It is early: most of the game is not read yet.

- Easiest: download `metaphor-accessibility-v0.1.0-installer.exe`, press Enter on it and choose Run. It is the
  spoken installer in one file, with no unzipping. The zip, `metaphor-accessibility-v0.1.0.zip`, holds the same
  installer for anyone who prefers it.
- Install it with [the install guide](https://github.com/Sour-Dev-Home/metaphor-accessibility/blob/main/docs/players/how-to/install-the-mod.md).
- Check your download first with
  [the download check](https://github.com/Sour-Dev-Home/metaphor-accessibility/blob/main/docs/players/how-to/check-a-download.md).
  The exe and the zip are listed in `SHA256SUMS`, and both are attested.
- What changed is in the
  [CHANGELOG](https://github.com/Sour-Dev-Home/metaphor-accessibility/blob/main/CHANGELOG.md).

### Known limits

- Steam version only, on one game build. After a game update the mod may not load until a new version is released.
- Only dialogue, reply choices, the title menu and the main menu are read. Other menus are in progress.
- Battle and moving around the field are not read.
- Tested with NVDA only. Other screen readers are untested.
- Parts of the installer and the mod were written without a screen reader to hand and are being checked by ear.
  If something is wrong, press `F8` when it happens, then follow
  [report a problem](https://github.com/Sour-Dev-Home/metaphor-accessibility/blob/main/docs/players/how-to/install-the-mod.md#report-a-problem).
