# Raw sources

Saved copies of what the notes rely on: community format write-ups, tool documentation, and captures of how the game
behaves. Never edit a file here. Add a new one, named `<topic>-<YYYY-MM-DD>.md`.

Each file starts with:
- where it came from (a URL, or the tool and its version);
- the date it was saved;
- the game build it applies to, if any.
