# DRM status of the PC (Steam) release

- **Source:** Steam store page <https://store.steampowered.com/app/2679460/Metaphor_ReFantazio/>, and PCGamingWiki read
  through its API (<https://www.pcgamingwiki.com/w/api.php?action=parse&page=Metaphor:_ReFantazio&prop=wikitext&format=json>),
  because the normal page returned HTTP 403.
- **Saved:** 2026-11-13.
- **Game build:** not stated by either source. It applies to the Steam release as sold on that date.

## Findings

- The Steam store page says: "Incorporates 3rd-party DRM: Denuvo Anti-tamper".
- PCGamingWiki's page source says: "All versions require {{DRM|Denuvo}}". It gives no date when Denuvo was removed.
- No statement from Atlus or Sega about Denuvo or about modding was found: [NEEDS VERIFICATION].

## Why it matters here

Ground rule 5 forbids bypassing DRM or anti-tamper protection. Which ways of analysing the game executable stay inside
that rule is a project decision. It isn't settled by this note.
