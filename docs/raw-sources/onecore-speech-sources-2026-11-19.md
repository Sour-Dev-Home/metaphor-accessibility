# Sources for the installer's OneCore voice (#509): the Windows Runtime speech API from Windows PowerShell 5.1

- **Source:** Microsoft Learn reference pages, read on the date below (URLs in each section); and a run on Windows 11
  (build 26200) in Windows PowerShell 5.1.26100.9818 (CLR 4.0.30319.42000), steps under "Checked here". No sound was
  played.
- **Saved:** 2026-11-19.
- **Game build:** none; this is about Windows, not the game.

## Windows.Media.SpeechSynthesis

- `SpeechSynthesizer`
  (<https://learn.microsoft.com/en-us/uwp/api/windows.media.speechsynthesis.speechsynthesizer?view=winrt-26100>):
  "Provides access to the functionality of an installed speech synthesis engine (voice) for Text-to-speech (TTS)
  services." C# `public sealed class SpeechSynthesizer : System.IDisposable`; Windows 10 10.0.10240.0,
  `UniversalApiContract` v1.0. "By default, a new SpeechSynthesizer object uses the current system voice." Members used:
  - `AllVoices` (`.../speechsynthesizer.allvoices`): `public static IReadOnlyList<VoiceInformation> AllVoices { get; }`,
    "Gets a collection of all installed speech synthesis engines (voices)." Static, so it is read from the type, not an
    instance.
  - `DefaultVoice` (`.../speechsynthesizer.defaultvoice`): `public static VoiceInformation DefaultVoice { get; }`.
  - `Voice` (`.../speechsynthesizer.voice`): `public VoiceInformation Voice { get; set; }`, "The default value is the
    current system voice."
  - `SynthesizeTextToStreamAsync(String)`: "Asynchronously generate speech output from a string." The page's example
    awaits it as a `SpeechSynthesisStream`.
  - `Close()`/`Dispose()`: "Closes the SpeechSynthesizer and releases system resources."
- `VoiceInformation` (<https://learn.microsoft.com/en-us/uwp/api/windows.media.speechsynthesis.voiceinformation?view=winrt-26100>):
  `DisplayName`, "Gets the display name associated with the speech synthesis engine (voice)"; `Language`, "Gets the
  normalized BCP-47 language tag of the speech synthesis engine (voice)"; `Id`, "Gets the unique ID".
- `SpeechSynthesisStream`
  (<https://learn.microsoft.com/en-us/uwp/api/windows.media.speechsynthesis.speechsynthesisstream?view=winrt-26100>):
  "Supports reading and writing audio data generated by the speech synthesis engine (voice) to/from a random access
  stream." Implements `IDisposable`, `IInputStream` and `IRandomAccessStreamWithContentType`; `ContentType`, "Gets the
  MIME type of the content".

## .NET's bridges (System.Runtime.WindowsRuntime.dll)

- `WindowsRuntimeSystemExtensions.AsTask<TResult>(IAsyncOperation<TResult>)`
  (<https://learn.microsoft.com/en-us/dotnet/api/system.windowsruntimesystemextensions.astask?view=netframework-4.8>,
  which serves the `dotnet-uwp-10.0` page): "Returns a task that represents a Windows Runtime asynchronous operation
  returns a result." Namespace `System`.
- `WindowsRuntimeStreamExtensions.AsStreamForRead(IInputStream)`
  (<https://learn.microsoft.com/en-us/dotnet/api/system.io.windowsruntimestreamextensions.asstreamforread?view=netframework-4.8>,
  same): "Converts an input stream in the Windows Runtime to a managed stream". Namespace `System.IO`.

Both pages list only the UWP moniker; that the assembly loads in Windows PowerShell 5.1 is from the run below.

## System.Media.SoundPlayer (System.dll)

<https://learn.microsoft.com/en-us/dotnet/api/system.media.soundplayer?view=netframework-4.8>: "Controls playback of a
sound from a .wav file." "supports loading a .wav file from ... a Stream that contains a .wav file". `SoundPlayer(Stream)`
"attaches the .wav file within the specified Stream"; `PlaySync()` "Plays the .wav file and loads the .wav file first if
it has not been loaded"; "If you call a synchronous load or play method, the calling thread will wait until the method
returns". "cannot play other file types, such as .wma or .mp3."

## Checked here

In `powershell.exe -NoProfile`, Windows 11 build 26200, Windows PowerShell 5.1.26100.9818:

1. `Add-Type -AssemblyName System.Runtime.WindowsRuntime` loads.
2. `$t = [Windows.Media.SpeechSynthesis.SpeechSynthesizer, Windows.Media.SpeechSynthesis, ContentType = WindowsRuntime]`
   resolves. `$t::AllVoices` listed `Microsoft David`, `Microsoft Zira` and `Microsoft Mark`, each `en-US`, with Ids
   under `HKEY_LOCAL_MACHINE\SOFTWARE\Microsoft\Speech_OneCore\Voices\Tokens\`; `$t::DefaultVoice` was Microsoft David.
   The same properties read through an instance (`(New-Object $t).AllVoices`) came back empty, as they are static.
   `$t::AllVoices.Count` printed `1 1 1` (PowerShell enumerates the list), so the count is taken with `@(...)`.
3. On the same machine, System.Speech's `GetInstalledVoices()` listed only `Microsoft David Desktop` and
   `Microsoft Zira Desktop` (`en-US`): the OneCore voices are not among them.
4. `SynthesizeTextToStreamAsync('Hello')`, waited on through `AsTask` made generic on
   `[Windows.Media.SpeechSynthesis.SpeechSynthesisStream, Windows.Media.SpeechSynthesis, ContentType = WindowsRuntime]`
   (the overload picked by name `AsTask`, one generic argument and one parameter of type `IAsyncOperation`1`), finished
   within 10 s; the stream's `ContentType` was `audio/wav`, `Size` 41006, and the first 12 bytes read through
   `AsStreamForRead` began `RIFF` with `WAVE` at offset 8.

In PowerShell 7.7.0 (pwsh) on the same machine, the module's OneCore engine does not start and the installer falls back to
System.Speech, which chose `Microsoft David Desktop`.

`tests/pester/check-install.Tests.ps1` repeats step 4 through the module's own functions on every run.
